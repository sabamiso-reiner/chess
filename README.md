# chess

ターミナルで2人対戦できるチェスです。

- チェック・チェックメイトの判定はありません（キングを取ったら勝ち）
- キャスリング・アンパッサンは使えません
- 棋譜は実行したディレクトリの `Score` ファイルに保存されます

## すぐに遊ぶ（Windows）

ビルドしなくても遊べます。

1. [Releases](../../releases) から最新版の `chess.exe` をダウンロードします。
2. `chess.exe` をダブルクリックして起動します。
3. 初めて起動したときに「Windows によって PC が保護されました」と表示された場合は、「詳細情報」をクリックしてから「実行」を押してください。（署名をしていない exe のため表示される警告です）
4. 対局が終わると「Enterキーを押すと終了します」と表示されます。Enter キーを押すとウィンドウが閉じます。

棋譜（`Score`）は `chess.exe` と同じフォルダに保存されます。

Windows 10 / 11 で動作します。駒の記号が □ や ? になる場合は、下の「[駒の記号が表示されない場合](#駒の記号が表示されない場合)」を見てください。

## ビルド

ソースコードは UTF-8 で書かれています。

### GCC / Clang（Linux・macOS・Windows の MinGW-w64）

```sh
gcc -o chess chess.c
```

Windows で C コンパイラが入っていない場合は、[WinLibs](https://winlibs.com/) などから MinGW-w64（GCC）をインストールしてください。

### Visual Studio（MSVC）

`/utf-8` を必ず付けてください。付けないと日本語環境ではソースが Shift_JIS として読まれ、文字化けします。

```bat
cl /utf-8 chess.c
```

## 実行

使っているターミナルに合わせて入力してください。

| ターミナル | コマンド |
|---|---|
| Linux・macOS・Windows の PowerShell | `./chess` |
| Windows のコマンドプロンプト | `chess` |

Windows では起動時にコンソールを自動で UTF-8 に切り替え、終了時に元に戻します。

### 駒の記号が表示されない場合

駒は Unicode のチェス記号（♔♕♖♗♘♙）で表示します。フォントが対応していない環境（古いコマンドプロンプトなど）では □ や ? になることがあります。その場合は Windows Terminal などを使うか、`--ascii` を付けて英字表示にしてください。

```sh
./chess --ascii
```

ダブルクリックでは `--ascii` を付けられません。`chess.exe` のあるフォルダでコマンドプロンプトや PowerShell を開き、上のコマンドで起動してください（コマンドプロンプトの場合は `chess --ascii`）。

英字表示では白が大文字、黒が小文字です（P: ポーン、N: ナイト、B: ビショップ、R: ルーク、Q: クイーン、K: キング）。

## 遊び方

1. 起動すると、白（先手）と黒（後手）のプレイヤー名を聞かれます。名前には**スペースを入れないでください**（スペースの前後で別の名前として扱われてしまいます）。
2. 盤面が表示されます。白が下側、黒が上側です。列は左から `a`〜`h`、段は下から `1`〜`8` です。

   ```
     +---+---+---+---+---+---+---+---+
   8 | r | n | b | q | k | b | n | r |
     +---+---+---+---+---+---+---+---+
   ...
     +---+---+---+---+---+---+---+---+
   1 | R | N | B | Q | K | B | N | R |
     +---+---+---+---+---+---+---+---+
       a   b   c   d   e   f   g   h
   ```

3. 自分の番では、まず**動かしたい駒のマス**を入力し（例: `e2`）、次に**移動先のマス**を入力します（例: `e4`）。列の英字と段の数字を続けて、半角で入力してください。
4. 移動先を聞かれたときに `z9` のように盤の外のマスを入力すると、動かす駒の選び直しができます。
5. ポーンが最奥の段に着くとプロモーションします。なりたい駒の番号を**半角数字**で入力してください（1: クイーン、2: ルーク、3: ビショップ、4: ナイト）。
6. 相手のキングを取ったプレイヤーの勝ちです。

## 注意

- プロモーションの番号は半角数字で入力してください。全角数字（`１`）や数字以外を入力した場合は、もう一度聞き直されます。
- 途中でやめるには Ctrl+C を押します。ただし、この方法で終了するとその対局の棋譜は `Score` に保存されません。
- `Score` は起動するたびに上書きされます。残しておきたい棋譜は、次の対局の前に別の名前でコピーしてください。
